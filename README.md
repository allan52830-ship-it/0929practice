# Flask Hello World 一頁式網站

這是一個基於 Python Flask 框架建置的現代風格 Hello World 一頁式網站。

---

## 專案結構

```text
practice0929/
│
├── app.py                  # Flask 主程式與路由定義
├── requirements.txt        # 相依套件清單
├── templates/
│   └── index.html          # 一頁式網站前端模板（含現代化 CSS 樣式與互動腳本）
└── README.md               # 專案說明文件
```

---

## 快速啟動

### 1. 安裝相依套件（若尚未安裝）
```bash
pip install -r requirements.txt
```

### 2. 啟動伺服器
```bash
python app.py
```

### 3. 開啟瀏覽器檢視
啟動後在瀏覽器開啟：
[http://127.0.0.1:5000](http://127.0.0.1:5000)
